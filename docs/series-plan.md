# 전체 연재 계획

개발 글 16편 + 이론 글 56편 = 총 72편. 모두 기획 상태이며 1편만 최신 사용자 수정 원고를 보존했다. 개념 하나당 한 편의 원칙을 유지한다.

각 기능의 개발 글에서 문제·서비스 제공 이유·제약·구현을 설명하고, 이어지는 이론 글에서 선택 근거·원리·작은 예제·대안 실험·한계를 깊게 공부한다. 모든 글에서 여러 선택지를 억지로 만들지는 않는다. 데이터 표현처럼 규격을 따라야 하는 주제는 해석의 정확성과 오류 조건에 집중한다.

이론 편수는 적용 완료 개념의 개수가 아니다. 실제 적용 사례와 확장 학습을 본문에서 구분한다. 힙, 가상 메모리, 격리 수준, MVCC, 프로세스 격리의 보장 범위, 취소 전파, 멱등성, 암달의 법칙, 리틀의 법칙, 일부 검증 방법 등은 적용이나 검증 결과를 별도 확인해야 한다.

## 작성 시 공통 기준

- 당시 선택, 사후 검증, 추가 비교를 구분한다.
- 개념별 심화 글을 유지하되 정의만 나열하지 않는다.
- 기술 선택은 개인의 최초 동기를 확인하고 작성한다.
- 코드에서 확인한 적용 범위와 실험으로 확인한 효과를 구분한다.
- 작은 예제, 실제 코드 경로, 실패 조건을 모두 포함한다.
- 현재 목차는 기획이며 완료된 구현·측정·원고의 목록이 아니다.
