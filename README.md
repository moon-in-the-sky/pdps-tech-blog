## 연재의 방향

서비스가 필요한 이유와 개발상의 문제를 설명하고, 가능한 방법을 비교해 선택 근거를 제시합니다. 그 판단에 필요한 이론은 개념마다 별도의 글로 깊게 다룹니다.

글의 기본 흐름은 문제 → 요구사항·제약 → 선택지 → 비교 기준 → 선택·구현 → 검증·한계 → 선택을 바꿀 조건입니다.

당시 실제로 비교한 선택지, 구현 후 확인한 결과, 글을 준비하며 추가로 조사한 대안은 구분합니다. 코드에서 확인한 사실만으로 개발자의 최초 의도를 추정하지 않습니다.

## 운영 방식

`docs/series-plan.md`에서 순서를 확인하고, `templates/article.md`를 복사하여 각 원고를 작성합니다. 실제 구현을 다루는 원고에는 확인한 커밋과 파일·함수를 기록합니다. 성능 수치는 측정 조건 및 원본 기록과 함께 관리합니다.

업로드한 프로토콜 PDF는 이 저장소 문서 묶음에 포함하지 않았습니다. 참고 자료 목록은 작성 지침에 기록했습니다.
